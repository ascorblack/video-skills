# Эффект → библиотека [Стек]

Начинайте с эффекта, который нужен шоту, затем берите первую библиотеку, которая его даёт. Если библиотека не делает шот заметно лучше, чем сама основа рендера, не добавляйте её: каждая — ещё один способ сломать перемотку, зависимость, версию которой нужно зафиксировать, и лицензия, которую нужно записать.

## Карта

| Что нужно шоту | Первый выбор | Альтернативы | Примечание |
|---|---|---|---|
| Заголовки, кинетическая типографика, карточки функций, появление логотипа | сама основа рендера (Remotion `interpolate`/`spring`, HyperFrames GSAP + реестр) | Anime.js для SVG/DOM-траекторий и поочерёдных анимаций | Для большей части моушн-дизайна дополнительная библиотека не нужна |
| Упругие, пружинящие движения интерфейса | пружина основы рендера (Remotion `spring()`; кривые GSAP `elastic`/`back`) | аналитическая пружина из `t` | React Spring работает по реальному времени — см. `seekable-libraries.md` |
| Прорисовка SVG-линий, морфинг контуров, поочерёдная анимация сеток | Anime.js v4 | GSAP (в HyperFrames уже есть) | |
| Точная векторная геометрия: кривые Безье, булевы операции с контурами, рисованные схемы | Paper.js | SVG + Anime.js | Paper.js — для геометрии, не для тайминга |
| Тысячи спрайтов, насыщенные 2D-сцены, 2D-фильтры | PixiJS | p5.js для экспериментов | WebGL/WebGPU canvas, без собственного таймлайна |
| Генеративные и алгоритмические фигуры, поля шума | p5.js | PixiJS, фрагментный шейдер | Фиксируйте seed для `random` и `noise` |
| Пыль, искры, конфетти, соединённые точки | tsParticles для быстрой пробы вида | частицы, вычисляемые из `t` в PixiJS или canvas | В tsParticles нет перемотки — запекайте или заменяйте |
| Переходы на GPU: шторки, деформации, глитч, прожиг | HyperFrames `@hyperframes/shader-transitions`; Remotion `@remotion/transitions` | шейдеры GL Transitions в собственном проходе WebGL | Один шейдер на весь ролик — см. `SKILL.md`, «Где источники расходятся» |

| Падающие, отскакивающие, сталкивающиеся плоские объекты | Matter.js с запеканием | Rapier 2D с запеканием | Физический движок не рисует |
| Твёрдые тела в 3D: столкновения, инерция, стопки | Rapier 3D (детерминированная сборка) с запеканием, отрисовка через Three.js | ручные ключевые кадры для короткого движения | |
| Озвучка | запись диктора или согласованный провайдер TTS; локально Chatterbox | | Правила дословности относятся к любому синтезу — `video-audio`, `voiceover.md` |
| Процедурные звуковые акценты, нарастания, ритмические подложки | Tone.js с офлайн-рендером в WAV | записанные SFX-файлы, сведённые через FFmpeg | |
| Субтитры и тайминг слов из голосовой дорожки | faster-whisper с временными метками слов | собственные метки слов провайдера TTS (HeyGen в HyperFrames `media-use`) | Распознавание, не синтез; вычитывайте термины |

## Чего библиотека не делает

- **Three.js** рисует; не моделирует физику и не имеет таймлайна. Его `Clock` и `AnimationMixer.update(delta)` работают по реальному времени — используйте `mixer.setTime(t)`.
- **Matter.js и Rapier** вычисляют позиции; ничего не рендерят и не знают о кадрах. Фиксируйте шаг, запекайте, затем рисуйте.
- **GL Transitions** — набор фрагментных GLSL-шейдеров (`vec4 transition(vec2 uv)` с uniform-переменной `progress`). Это не редактор, и таймлайна у него нет: кто-то должен захватить обе сцены как текстуры и подать `progress` из номера кадра.
- **tsParticles** анимирует в собственном цикле и не может перейти к кадру N.
- **React Spring** интегрирует пружины по реальному времени; рендер, который берёт кадры в произвольном порядке, получает неверные значения.
- **faster-whisper** превращает речь в текст с таймингами; он не генерирует голос. **Chatterbox** генерирует голос; он не даёт таймингов слов.
- **Tone.js** играет через Web Audio в реальном времени, если не рендерить через `Tone.Offline`; живой транспорт Tone.js внутри покадрового рендера рассинхронизирован по самой своей природе.
- **OBS** пишет в реальном времени; сделать запись покадрово точной задним числом нельзя.
- **p5.js** перерисовывает в собственном цикле со своим `frameRate`, пока не получит `noLoop()`.

## Что можно предложить по запросу

- Анимированные интерфейсы: настоящие записи с выносными подписями; меню, переключатели и пошаговые демонстрации рисуют только там, где этого требует стилизация [Научпоп], — промо показывает настоящую программу [Видео].
- Техническая визуализация: схемы архитектуры, потоки запросов, очереди, обходы графов, графики — с правилами линий из `video-design` (`lines-and-layout.md`).
- Моушн-графика: кинетическая типографика, морфинг векторных контуров, движущиеся сетки, процедурные фигуры, шейдерные переходы.
- 2D и 3D: плотные системы частиц, 2D-физика, 3D-продукты и каркасные модели, облёты камеры, симуляции твёрдых тел.
- Звук: дикторский текст, процедурные звуковые акценты, музыка под голосом, визуализаторы в такт дорожке, субтитры по таймингам слов.

Заранее предупреждайте о дорогих задачах: фотореалистичные люди, точная копия сложного настоящего приложения, физически точная CGI и длинные кинематографичные истории требуют специально подготовленных ассетов, заранее отрендеренных фрагментов и гораздо больше работы. Упоминание библиотеки не превращает ничего из этого в задачу на один клик.
