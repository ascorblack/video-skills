# Голос, процедурный звук и тайминг слов [Стек]

Три инструмента из источника решают три разные задачи, и их легко перепутать: **Chatterbox** делает речь из текста, **faster-whisper** — текст с таймингами из речи, **Tone.js** — музыку и звуковые эффекты из кода. Правила сведения (уровни под голосом, LUFS, истинный пик) от инструмента не меняются — они в навыке `video-audio`, `mixing.md`.

## Chatterbox — локальный TTS

- Установка: `uv pip install "chatterbox-tts @ git+https://github.com/resemble-ai/chatterbox"` (Python ≥ 3.10; разработан на 3.11; настоятельно рекомендуется GPU с CUDA). Лицензия MIT. Релиз `chatterbox-tts` 0.1.7 на PyPI вышел до Multilingual V3: его `from_pretrained` не принимает `t3_model` и загружает V2, поэтому пример ниже на нём падает с `TypeError`. Установите из репозитория (зафиксируйте коммит) либо уберите `t3_model` и используйте V2.
- Модели: **Multilingual V3** (0.5B, 23 языка, включая русский) — для озвучки не на английском; **Turbo** (350M) и **Nano** (110M, может работать на CPU) — только для английского, поддерживают теги вроде `[laugh]`, `[cough]`.

```python
import torchaudio as ta
from chatterbox.mtl_tts import ChatterboxMultilingualTTS

model = ChatterboxMultilingualTTS.from_pretrained(device="cuda", t3_model="v3")
wav = model.generate("Текст одной фразы.", language_id="ru",
                     audio_prompt_path="voice_ref_10s.wav",   # optional voice reference
                     exaggeration=0.5, cfg_weight=0.5)
ta.save("phrase_01.wav", wav, model.sr)
```

- Генерируйте **одну фразу на файл**, из того же списка, из которого строится экранный текст [Видео]: неудачную фразу перегенерируют отдельно, и у каждой фразы своё начало на таймлайне.
- Значения по умолчанию `exaggeration=0.5, cfg_weight=0.5` подходят для большей части текстов. Быстрая речь в образце — снижайте `cfg_weight` примерно до 0.3. Больше выразительности — `exaggeration` 0.7+ с `cfg_weight` около 0.3 (большая выразительность ускоряет речь).
- Образец должен быть на языке `language_id`; иначе речь наследует его акцент — тогда ставьте `cfg_weight=0`.
- Клонированный голос: только собственный или с письменным согласием владельца; никогда не имитируйте реального человека, который не согласился. Каждый результат содержит неслышимый водяной знак Perth от Resemble AI, который переживает кодирование в MP3, — запишите это в список ассетов.
- Дословность синтеза не гарантирована: действует та же проверка, что для любой модели, — независимое распознавание готового аудио, пословное сравнение, перегенерация при расхождении [Звук] (`video-audio`, `voiceover.md`). faster-whisper ниже — такой распознаватель.
- В начале каждого файла немного тишины; ставьте фразу по началу речи в ней, а не по началу файла [Научпоп].
- Упоминание модели в источнике не обещает качества русского: прежде чем поручать ей всю озвучку, прослушайте тестовый абзац с именами, числами и терминами.

## faster-whisper — временные метки слов

- Установка: `uv pip install faster-whisper` (CTranslate2; GPU с CUDA или CPU с `int8`). `scripts/words.py` оборачивает вызов ниже и записывает `words.json` и `.srt`.

```python
from faster_whisper import WhisperModel

model = WhisperModel("large-v3", device="cuda", compute_type="float16")  # CPU: device="cpu", compute_type="int8"
segments, info = model.transcribe("voice.wav", language="ru", word_timestamps=True,
                                  vad_filter=True, initial_prompt="HyperFrames, Remotion, ffmpeg")
for seg in segments:            # a generator: transcription runs while iterating
    for w in seg.words:
        print(w.start, w.end, w.word, w.probability)
```

Применение в ролике:

- **Субтитры.** Собирайте слова в строки по паузам и длине, а не по фиксированному количеству; строка субтитров появляется на первом слове и держится, пока её не дочитают [Видео]. Затем вычитка человеком: в терминах, именах, числах и слитных словах распознавание ошибается [Звук]. Передавайте термины проекта в `initial_prompt` (или `hotwords`), чтобы уменьшить такие ошибки, но не устранить их полностью.
- **Проверка дословности синтеза.** Распознавайте каждую сгенерированную фразу и сравнивайте со сценарием по словам; прежде чем браковать, посмотрите различия глазами [Звук].
- **Подгонка картинки под голос.** Начала слов дают моменты для слайдов (за 0.5–0.7 с до фразы) и действий на экране; начало первого слова — начало речи в дубле [Видео] [Научпоп].
- **Склейки между словами.** Промежутки между словами показывают, где резать безопасно; собственный детектор пауз из уроков — в `video-audio`, `voiceover.md` [Научпоп].
- Распознавайте готовую голосовую дорожку, а не микс: музыка под голосом сдвигает границы слов и добавляет выдуманные слова в паузах (против последнего помогает `vad_filter=True`).

## Tone.js — процедурный звук

- Tone.js — это Web Audio: работает в браузере (или headless Chrome), а не в обычном Node. Живой транспорт Tone.js внутри покадрового рендера не привязан к кадрам рендера, поэтому не запускайте его воспроизведение во время рендера.
- Вместо этого рендерите офлайн и вшивайте WAV как любую другую дорожку [Видео] (навык `video-render`, `mux-and-delivery.md`):

```js
import * as Tone from "tone";

const seconds = 12;
const buffer = await Tone.Offline(({ transport }) => {
  const synth = new Tone.PolySynth().toDestination();
  // times come from the shot table, in seconds — the same numbers the picture uses
  transport.schedule(t => synth.triggerAttackRelease(["C4", "G4"], "8n", t), 1.25);
  transport.start(0);
}, seconds, 2, 48000);

const audioBuffer = buffer.get();     // a standard AudioBuffer → encode to 16/24-bit WAV and save
```

- Планируйте звуковые события по тем же таймингам, что картинку, — по моменту видимого приземления объекта, а не по оценке из раскадровки [Звук] (`video-audio`, `sound-design.md`).
- Любая случайность (очеловечивание тайминга, случайные ноты) — из генератора с фиксированным seed, чтобы повторный рендер давал ту же дорожку, а прежние версии пересобирались побайтно [Звук].
- Офлайн-рендер идёт быстрее реального времени и без выпадений; результат затем измеряется и сводится как записанный файл — Tone.js не заменяет проверки громкости и истинного пика.
